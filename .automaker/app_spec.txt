  <project_name>Cyberpunk Stacks</project_name>

  <overview>
    A shareable, static single-page web application that renders a cyberpunk &quot;mega-highrise&quot; building as a side-view visualization, inspired by Kowloon Walled City aesthetics. The app displays a data-driven, clickable building map with configurable floors, where each floor contains multiple &quot;blocks&quot; (rectangles) representing different spaces such as residences, businesses, warehouses, clinics, temples, clubs, and more. Users can interact with blocks to view detailed information including descriptions, occupants, security ratings, loot, and active events. A &quot;Next Beat&quot; feature allows re-rolling events using deterministic RNG. The entire application runs as a static site with no backend, powered by a comprehensive JSON data file containing extensive tables for locations, events, items, NPCs, factions, security systems, and plot twists.
  </overview>
